## ✨ Features

1. **Branded Login Portal**: Clean, modern glassmorphic interface branded "karthikeya" with role toggling.
2. **Dashboard with "Today's Task Updated ✓" Status**:
   - A prominent status banner verifying whether today's study tasks have been updated.
   - Shows a green checkmark badge (`✓`) once tasks are logged.
   - Summarizes total study hours and minutes, top focus topic, and completion percentage.
3. **Daily Task Sheet**:
   - Add/edit/delete tasks for any date.
   - Fields: **Topic/Subject** (Math, Science, English, Programming, etc.), **Task Details**, and **Time Spent on Topic** (hours & minutes).
   - Interactive tick mark checkboxes to mark tasks completed (with confetti celebration 🎉).
   - Built-in live study stopwatch timer with "Use in Task" shortcut.
4. **Dad's Review & Comments Corner**:
   - Dedicated space for Dad to write feedback, encouragement, and advice.
   - "Dad Approved ✓" official stamp of approval.
   - Quick encouragement tags for rapid feedback.
5. **Data Persistence & Export**:
   - Automatically saves to browser `localStorage`.
   - Export to CSV button for spreadsheets.
   - Printer-friendly stylesheet for printing daily study sheets.
