🧠 Discovery 1: Thinking Token Bloat

On Question 1, the LLM spent 330 thinking tokens vs only 151 final answer tokens. Raw code forces the model to search blindly through irrelevant lines.

→ Action: AST type stubs eliminate internal search time.
⏳ Discovery 2: The 30-Second Latency Spike

Response time was 29.76 seconds. In real developer IDEs, engineers abandon queries that take over 10 seconds.

→ Action: Surgical slicing cuts latency down to ~2-4s.
🔒 Discovery 3: Security & Context Noise

Sending whole files leaks internal helpers and credentials to cloud LLMs. Baseline has zero privacy boundary.

→ Action: AST pre-sanitizer redacts keys before prompt.
